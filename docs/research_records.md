# Reading the research records

The component reports describe experiments performed while developing the method. Some
were written before the final ProGen2/evolution entry was selected, so their candidate
counts, model versions and generator mixtures differ from the submitted library.

Use [the method](method.md) for the selected approach,
[the submission manifest](../portfolio-selection/reports/submission_entry_manifest.json)
for final counts and hashes, and [the model cards](../shared-evaluator/reports/model_cards.md)
for the activity and hemolysis models used in the final analysis. The
[historical replay report](FULL_REPLAY_VERIFICATION.md) states what was reproduced.

Older four-generator comparisons remain as research records. Their tables are not the final
ranking, and model-based success simulations are not wet-lab success estimates. Some
supporting raw tables are retained only in the private archive. A report referencing a file
there does not imply that the file is present in the public checkout.
