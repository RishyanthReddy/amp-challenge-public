# Diffusion baseline records

The generation and candidate-analysis manifests describe the recorded Beam RTX 4090
baseline run. The executed runner is preserved as
`diffusion_pipeline_source_6b93faa31252.py`, with fingerprints in the manifests.
The [baseline guide](../README.md) describes the hash-pinned public checkpoint download.

Raw candidate tables and timing CSVs remain in the private archive. The physical verifier
requires those files and does not run from the public checkout alone. Diffusion-generated
sequences are excluded from the submitted library; see
[research-record guidance](../../docs/research_records.md).
