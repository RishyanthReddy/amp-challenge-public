# Published baseline experiments

This directory retains documentation for experimental results associated with the upstream
AMP-Diffusion study. The experimental CSV tables are not bundled in this public checkout.
For the published measurements, see Torres et al., *Generative latent diffusion language
modeling yields anti-infective synthetic peptides*, *Cell Biomaterials* 1, 100183 (2025),
[doi:10.1016/j.celbio.2025.100183](https://doi.org/10.1016/j.celbio.2025.100183).

Those published baseline assays are separate from our newly generated sequences. The
submitted [Top 100](../../generate/top.fasta) has not been experimentally assayed by this
project, and contains no AMP-Diffusion baseline output.
