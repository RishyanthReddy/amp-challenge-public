# Retained DBAASP exports

These five files are the original inputs used by this project, unchanged. Their sizes and SHA-256 hashes are recorded in [the source manifest](../../../../docs/training_sources.json). Acquisition dates, export queries and provider release labels were not recorded and remain unknown.

Data source: **Database of Antimicrobial Activity and Structure of Peptides (DBAASP)**. Cite Pirtskhalava et al., *DBAASP v3*, Nucleic Acids Research (2021), DOI [10.1093/nar/gkaa991](https://doi.org/10.1093/nar/gkaa991).

The [current DBAASP terms](https://dbaasp.dbaasp.niaidprod.net/terms-and-conditions), reviewed 2026-09-29, permit downloading, copying, using, adapting and redistributing data with acknowledgment. These retained source exports are supplied with that acknowledgment. The repository MIT license applies to original software; it does not replace source terms.

The files include observational assay rows. Project curation normalizes sequences, removes ineligible constructs, retains source IDs, and defines deterministic partitions; it does not turn predicted activity into a measured assay. See [data processing](../../../README.md).
